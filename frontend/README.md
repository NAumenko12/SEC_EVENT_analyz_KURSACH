# Пользовательский интерфейс

В этом каталоге будет React-интерфейс Security Event Analyzer. Через него
пользователь сможет загрузить журнал или PCAP-файл, наблюдать за выполнением
анализа, фильтровать нормализованные события и читать сформированный отчёт.

Frontend начнём собирать после того, как API научится читать справочники из
PostgreSQL и создавать задачи анализа. Такой порядок позволит строить интерфейс
вокруг уже работающего контракта API, а не дублировать временные тестовые данные.
