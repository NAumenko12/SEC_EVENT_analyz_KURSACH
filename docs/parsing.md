# Парсинг событий

Первый настоящий парсер обрабатывает системный журнал Linux `auth.log`. Worker
передаёт код источника фабрике `createParser()`. Для `auth_log` фабрика создаёт
`AuthLogParser`, реализующий общий интерфейс `EventParser`. Форматы, для которых
парсер ещё не написан, завершаются понятной ошибкой, а не имитируют успешный
анализ.

Чтение строк выполняет общий `TextLogReader`. Конкретный парсер отвечает только
за преобразование одной строки в `NormalizedEvent`. Благодаря этому будущий
`NginxLogParser` можно добавить в фабрику, не изменяя основной цикл worker.

## Поддерживаемые строки

Парсер распознаёт:

- неудачный SSH-вход — `failed_ssh_login`;
- вход с неизвестным именем — `invalid_user_login`;
- успешный SSH-вход — `successful_ssh_login`;
- выполнение команды через `sudo` — `sudo_command`.

Для события сохраняются время, тип, критичность, результат, IP-адрес и порт
источника, hostname, пользователь, процесс, понятное сообщение, исходная строка
и её номер в файле. IPv4 и IPv6 проверяются типом `INET` в PostgreSQL.

Классический формат syslog не содержит год. Парсер использует текущий год, а
если полученная дата оказалась более чем на сутки в будущем — предыдущий. Это
позволяет корректно загружать журналы на границе нового года.

Неизвестная строка учитывается в `processed_records`, но не превращается в
событие. Это важно: система не должна придумывать данные, если формат ей не
знаком. Количество распознанных строк записывается в `events_created`.

## Целостность записи

События, итоговые счётчики, состояние `completed` и история состояния
сохраняются в одной транзакции. Если хотя бы одно событие не проходит
ограничения базы, транзакция откатывается, а worker переводит задание в
`failed`. Частично сохранённого анализа не остаётся.

Публичный метод `completeAnalysisJob()` управляет транзакцией. Формирование
`INSERT` находится в `saveEvents()`, а обновление задания и истории — в
`markAnalysisJobCompleted()`. Поэтому каждый метод решает одну задачу, но
атомарность всей операции сохраняется.

Проверить парсер отдельно от Kafka и PostgreSQL можно командой:

```bash
make test-worker
```
